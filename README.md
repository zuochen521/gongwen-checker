# gongwen-checker

# 公文校验系统（离线初版）

本程序在本机运行，不联网。需要带 Tkinter 的 Python 3，无第三方依赖。双击启动.bat，选择 docx，点击审核或生成副本。副本保存在原文件所在目录，不覆盖原件。

程序将第一个非空段落识别为标题（二号方正小标宋简体），按序号识别一级标题（三号方正黑体简体）、二级标题（三号方正楷体简体），其他段落一般设置为三号方正仿宋简体，并调整页边距。识别可能有误，表格、附件标题等尤其需要人工复核。电脑需安装相应方正字体，否则 Word 可能替换字体。

本版尚未完整实现段落、分页、印章及其他全部公文标准。复杂文档的特殊格式可能变化，务必保留原件并检查副本。
